# 物镜像素标定流程

1.  将像素长度校准玻片倒置放在玻片适配器或校正块上，然后放入载物台
    
    ![e859f494549a85267f12266af97950df.jpeg](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AR7gzdvOke/img/964a60a7-2ae9-4fb5-a716-df05a61833eb.jpeg)  ![f0033646c45c470d9259ca3d4c8a6689.jpeg](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AR7gzdvOke/img/6a6b2595-dfdd-4dd0-bacd-c8f0132b9a2f.jpeg)
    
2.  打开采集软件，设置脚本中的当前物镜为要校正的物镜，以10X举例
    
3.  切换到10X物镜，通过通过摇杆或界面的步进XYZ，找到物镜对准下图标尺时的位置和焦面
    
    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AR7gzdvOke/img/f9086dcb-c8c4-49f3-95b6-e9ad227a298b.png)
    
4.  找对图片的要求
    
    （1）视野中尽可能多的拍到刻度尺，减少测量误差
    
    （2）可通过视窗放大查看，确保能看到刻度尺边缘的弧度
    
    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AR7gzdvOke/img/452ecd67-a83f-421d-a54f-e85c4cb2ced7.png)
    
5.  图片确定后，点击快照，点击保存，图片保存到指定位置
    
    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AR7gzdvOke/img/2d2d3605-d21a-4b57-980f-8fcc9195d1af.png)
    
6.  使用FIJI打开保存的图片，设置像素， Image → Properties 设置正确的像素宽高比为1：1，点击ok
    
    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AR7gzdvOke/img/4c99cc58-b4fa-4dce-b2a9-504dba3ffc50.png)
    
7.  在最上和最下的两个刻度线上一条垂直线，Analyze → Measure（快捷键 **Ctrl+M**），读取画线所占的像素个数，可多测量几次，确保偏差不大。
    
    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AR7gzdvOke/img/43f6a9f0-0b1d-43d8-ae82-254412399d83.png)
    
8.  计算像素长度
    

（1）画线共占了100个小格，每个小格的刻度长度为10um

（2）画线共为1606个像素

计算： 100\*10/1606=0.622665
