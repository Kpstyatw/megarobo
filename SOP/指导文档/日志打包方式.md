# 日志打包方式

1.  打开HCS.Provider，输入CellVue，登录
    
    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Pd6l2Z7JEYNPNl7M/img/ccb5743a-aedf-40a2-b3d5-47eb1dba9556.png)
    
2.  数据-时间，选择包括发生问题的时间，点击Zip
    
    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Pd6l2Z7JEYNPNl7M/img/ce068c9e-1e07-42c8-af9d-06c12175e77d.png)
    
    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Pd6l2Z7JEYNPNl7M/img/a1435b8e-4ec4-4d62-841d-fed4523722b3.png)
    
3.  选择保存位置后，点击保存，会生成一个zip压缩文件
    
    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Pd6l2Z7JEYNPNl7M/img/19f2d5a7-e9c1-4695-825c-59d5ff8fb917.png)
    
4.  将压缩文件发给镁伽技术人员
